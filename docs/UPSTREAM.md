# Upstream

DF-AMP PLAYER is derived from **Dynamic Music** by **Numidium3rd / numidium**.

Upstream repository:

`https://github.com/numidium/dfu-mods/tree/main/DynamicMusic`

The upstream project is part of a multi-mod repository, so DF-AMP PLAYER is maintained as a separate repository rather than as a GitHub fork of the whole `dfu-mods` repository.
