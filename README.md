# DF-AMP PLAYER

Extended music-player project for **Daggerfall Unity**, based on the original **Dynamic Music** mod by **Numidium3rd / numidium**.

## Credits

- **Original mod:** Dynamic Music
- **Original author:** Numidium3rd / numidium
- **Original source:** numidium/dfu-mods → DynamicMusic
- **Original license:** MIT
- **DF-AMP extended player modifications:** **DF-AMP PLAYER BY RICO**

DF-AMP preserves and extends the original Dynamic Music playback work with an in-game player interface, NEXT control, dynamic track display, native HUD track-name feedback, menu/fast-travel integration, and additional playback behavior.

This is an independent derived project. It does not modify the original Dynamic Music repository.
